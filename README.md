# React PLC Diagram

A read-only React renderer for OpenPLC-style LD and FBD nodes.

The project starts from the OpenPLC Editor visual vocabulary:

- powerRail
- contact
- coil
- block
- block pins with attached variables
- orthogonal connections

The first milestone is deliberately read-only. PLCopen XML parsing and editor interactions will be added only after the node model and visual renderer are stable.
