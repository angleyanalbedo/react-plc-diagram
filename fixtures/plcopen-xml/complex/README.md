# Complex PLCopen XML fixtures

These fixtures are public PLCopen XML projects from the Spec2Control project:

- `paper-machine.xml` — `data/fbd-GPT5-generated/paper-machine/plc.xml`
- `coking-refinery.xml` — `data/fbd-GPT5-generated/coking-refinery/plc.xml`

Source: https://github.com/hkoziolek/Spec2Control

They are kept for parser and renderer stress tests. They contain multiple POUs, FBD blocks, variable nodes, and hundreds of connections.
