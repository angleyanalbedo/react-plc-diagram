# Repository agent instructions

- Treat read, create, and edit operations inside this repository as pre-authorized.
- Run non-destructive checks such as type checking, tests, builds, formatting, and Git status without asking for confirmation.
- Do not repeatedly request approval for an already approved command category.
- Confirmation is still required when enforced by the product for network access, writes outside this repository, GUI access, privilege escalation, or materially destructive operations.
- Never use destructive Git commands unless the user explicitly requests them.
